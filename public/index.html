02 · Sobre Nosotros

VialCore Tech y el origen de ParkSense 32

Innovación tecnológica nacida en Machala para transformar la movilidad en estacionamientos urbanos y comerciales.

Nuestra empresa y cómo surgió

VialCore Tech es un equipo multidisciplinario enfocado en soluciones IoT para infraestructura vial. El proyecto surgió al observar los cuellos de botella diarios en el parqueadero de La Piazza (Machala), donde los conductores recorrían los pasillos sin saber si existían plazas libres.

Problema que busca solucionar

La búsqueda manual de estacionamiento genera demoras de hasta 12 minutos, congestión en los carriles de maniobra, consumo innecesario de combustible y errores en el control manual de entradas, salidas y sentidos de circulación.

Propósito y necesidad del desarrollo

Nuestro propósito es brindar visibilidad inmediata de cada plaza antes de ingresar, automatizar las barreras de entrada y salida, alertar ingresos en contramano y ofrecer una consola web unificada para conductores, kiosco y administración.

03 · Nuestro Producto

ParkSense 32: gestión inteligente integral

Dispositivo IoT con microcontrolador ESP32 Dual-Core, sensórica ultrasónica por bahía, terminal de autoservicio y monitoreo web en tiempo real.

12 min → 40 seg

Asignación recomendada y acceso inmediato

ParkSense 32 evalúa la disponibilidad real de las 4 plazas (A1, A2, B1, B2), recomienda el espacio óptimo en el kiosco de entrada y eleva automáticamente la barrera servomotora tras confirmar el registro.

Visibilidad web y señalización física

LEDs verde/rojo en cada bahía, pantalla LCD 16x2 en el acceso y panel web sincronizado para consultar disponibilidad desde cualquier dispositivo.

Seguridad vial y alerta de contramano

Sensor infrarrojo en la salida acoplado a un buzzer acústico que detecta y alerta si un vehículo intenta ingresar en sentido contrario.

Sostenibilidad y auditoría centralizada

Menor tiempo con el motor en marcha reduce emisiones de CO₂ y gasto de combustible, mientras el sistema registra placas, tiempos de estancia y reportes CSV.

Criterio operativo Estacionamiento Tradicional ParkSense 32
Identificación de espacios Manual: el conductor recorre filas sin certeza de disponibilidad. Automática: visualización en pantalla web, LCD y LEDs por bahía.
Tiempo de búsqueda Elevado: entre 10 y 15 minutos en horas pico. Mínimo: asignación directa y guiada en menos de 40 segundos.
Automatización de acceso Nula o básica: tickets impresos y operación manual. Total: kiosco táctil, servomotores SG90 y cierre por sensor al pasar.
Control y seguridad Registros dispersos y sin alerta de ingreso en sentido contrario. Auditoría por placa/movimiento y alarma IR + buzzer de contramano.
04 · ¿Cómo Funciona?

Operación paso a paso y arquitectura electrónica

Desde el registro del conductor hasta la lectura de sensores y el accionamiento automático de las barreras.

01

Registro de placa

El conductor ingresa su placa en la terminal de autoservicio al llegar a la barrera de entrada.

02

Asignación inteligente

El sistema evalúa los espacios A1–B2 en tiempo real y recomienda el lugar óptimo disponible.

03

Apertura y paso por sensor

El servomotor eleva la barrera a 90°; cuando el sensor ultrasónico confirma que el auto pasó, la barrera baja.

04

Estacionamiento y salida

El sensor de la bahía cambia el LED a rojo y actualiza la web; al salir, libera el espacio automáticamente.

240 MHz · WiFi

ESP32 Dual-Core

Unidad central de procesamiento

Coordina lecturas ultrasónicas, servos, pantalla LCD, LEDs, buzzer y comunicación HTTP WiFi con el servidor Node.js.

40 kHz · Eco

Sensores Ultrasónicos HC-SR04

Detección en bahías y barreras

Miden distancia por ondas acústicas en las 4 plazas (A1–B2) y en las barreras de entrada/salida con inmunidad a luz solar.

PWM 0°–90°

Servomotores SG90

Accionamiento suave de barreras

Controlados mediante tarea independiente en FreeRTOS para elevar y bajar las talanqueras gradualmente sin picos de corriente.

Óptico IR · Pin 14

Sensor Infrarrojo FC-51

Detección de contramano

Vigila el exterior de la salida para detectar si alguien intenta ingresar en sentido contrario cuando la salida no está activa.

Acústico · Pin 27

Buzzer Zumbador

Alerta sonora inmediata

Emite pitidos intermitentes de advertencia durante al menos 3 segundos cuando el sensor IR detecta un ingreso indebido.

I2C 0x27

Pantalla LCD 16x2 I2C

Información en tiempo real

Muestra en el acceso el conteo actualizado de plazas libres y ocupadas sin ocupar múltiples pines del ESP32.

Señalización · GPIO

LEDs Rojo / Verde

Indicadores de estado por plaza

Iluminan verde cuando el espacio está libre y conmutan a rojo cuando el sensor ultrasónico detecta un vehículo estacionado.

Flujo lógico del sistema

  • 01Lectura de sensores: El ESP32 promedia 3 ecos por cada sensor HC-SR04 y evalúa el umbral (≤ 12 cm = ocupada).
  • 02Procesamiento y red: Actualiza LEDs/LCD y envía JSON cada 800 ms vía HTTP POST a /api/estado.
  • 03Comandos bidireccionales: El servidor responde con órdenes del Kiosco (abrir_auto) o del Admin (abrir/cerrar).
  • 04Respuesta de actuadores: Los servos SG90 abren suavemente la barrera y el sensor ultrasónico la cierra al completar el paso.

Mecanismo de comunicación Hardware ↔ Web

El microcontrolador ESP32 se conecta por WiFi (2.4 GHz) y envía cada 800 ms un paquete JSON mediante HTTP POST /api/estado con las distancias ultrasónicas y el estado de las barreras. El servidor Node.js persiste los datos en datos.json, responde con órdenes pendientes del Kiosco o Admin, y la web consulta GET /api/kiosco/resumen cada 2 segundos para actualizar el dashboard sin recargar la página.

07 · Proceso de Desarrollo

De la idea al prototipo funcional

Registro visual de las cinco etapas de construcción, montaje, programación y validación física.

Etapa 1

Componentes electrónicos utilizados

Selección y verificación individual de todos los componentes electrónicos necesarios para la detección vehicular, control automatizado de acceso, señalización visual/sonora y transmisión de datos en tiempo real.

Microcontrolador ESP32 con WiFi/Bluetooth
Sensores ultrasónicos HC-SR04
Sensor infrarrojo de obstáculos MH-B
Micro servomotores SG90 para barreras
Pantalla LCD 16x2 con interfaz I2C
LEDs indicadores de estado libre/ocupado
Módulo buzzer para alertas sonoras

Etapa 2 — Montaje electrónico en protoboard

Primer ensamblaje en protoboard para validar las conexiones del ESP32, lectura de sensores, conmutación de LEDs verde/rojo y comunicación I2C con la pantalla LCD.

Etapa 3 — Programación y calibración en Arduino IDE

Desarrollo del código en Arduino IDE (CANTIDAD_PLAZAS = 4), configuración de pines TRIG/ECHO y calibración de las lecturas de distancia en centímetros desde el Monitor Serie en tiempo real.

Etapa 4 — Pruebas de detección y respuesta

Validación funcional simulando el ingreso de vehículos: al detectar proximidad, el sistema activa la alerta, cambia el LED indicador de verde a rojo y actualiza los contadores de plazas libres y ocupadas.

Etapa 5 — Prototipo electrónico integrado (4 plazas)

Sistema completo interconectado con los 4 sensores ultrasónicos HC-SR04, sensor infrarrojo, 2 servomotores para barreras, buzzer, LEDs por puesto y pantalla LCD mostrando el estado general ('Libres: 4 de 4 | Ocupadas: 0').

import java.util.Scanner;

public class ProyectoIntegradorParqueadero {

    // Posición 0..3 -> A1, A2, B1, B2
    static final String[] NOMBRES_ESPACIOS = {"A1", "A2", "B1", "B2"};

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int seleccion;
        int espaciosTotales = 4;
        int libres;
        int ocupados = 0;
        int[][] mapa = new int[2][2];          // 0 = libre, 1 = ocupado
        String[] placas = new String[4];
        String[] tipoMovimiento = new String[20];
        String[] historialPlaca = new String[20];
        String[] historialEspacio = new String[20];
        int contadorHistorial = 0;

        // Inicializar los espacios como libres y las placas vacías
        for (int i = 0; i < 2; i++) {
            for (int j = 0; j < 2; j++) {
                mapa[i][j] = 0;
            }
        }
        for (int i = 0; i < 4; i++) {
            placas[i] = "";
        }

        seleccion = 0;
        while (seleccion != 8) {
            mostrarMenu();
            try {
                seleccion = Integer.parseInt(sc.nextLine().trim());
            } catch (NumberFormatException e) {
                seleccion = -1; // cae en la opción incorrecta
            }

            switch (seleccion) {

                case 1: {
                    libres = 0;
                    ocupados = 0;
                    for (int filas = 0; filas < 2; filas++) {
                        for (int columnas = 0; columnas < 2; columnas++) {
                            if (mapa[filas][columnas] == 0) {
                                libres++;
                            } else {
                                ocupados++;
                            }
                        }
                    }
                    System.out.println("                 DISPONIBILIDAD DEL PARQUEADERO");
                    System.out.println("Cantidad total de espacios: " + espaciosTotales);
                    System.out.println("Espacios libres: " + libres);
                    System.out.println("Espacios ocupados: " + ocupados);
                    break;
                }

                case 2: {
                    String espacioEncontrado = buscarEspacioLibre(mapa);
                    if (!espacioEncontrado.equals("LLENO")) {
                        System.out.println("                   REGISTRO DE INGRESO");
                        System.out.println("Hay espacios disponibles.");
                        System.out.println("Primer espacio disponible recomendado: " + espacioEncontrado);
                        System.out.println("Ingrese la placa del vehiculo:");
                        String placa = sc.nextLine();

                        boolean placaExiste = false;
                        for (int contador = 0; contador < 4; contador++) {
                            if (placas[contador].equals(placa)) {
                                placaExiste = true;
                            }
                        }

                        if (placaExiste) {
                            System.out.println("              VEHICULO YA REGISTRADO");
                            System.out.println("La placa " + placa + " ya se encuentra en el parqueadero.");
                            System.out.println("No es posible registrar nuevamente el vehiculo.");
                        } else {
                            System.out.println("                 SELECCION DE ESPACIO");
                            System.out.println("Espacios disponibles para seleccion:");
                            System.out.println("A1 - A2");
                            System.out.println("B1 - B2");

                            boolean espacioValido = false;
                            String espacioSeleccionado;
                            int posicionPlaca;
                            do {
                                System.out.println("Ingrese el identificador del espacio libre:");
                                espacioSeleccionado = sc.nextLine().trim();
                                posicionPlaca = obtenerPosicion(espacioSeleccionado);

                                if (posicionPlaca == -1) {
                                    System.out.println("Espacio incorrecto. Ingrese A1, A2, B1 o B2.");
                                } else if (mapa[posicionPlaca / 2][posicionPlaca % 2] == 1) {
                                    System.out.println("Ese espacio esta ocupado. Elija otro.");
                                } else {
                                    espacioValido = true;
                                }
                            } while (!espacioValido);

                            int filas = posicionPlaca / 2;
                            int columnas = posicionPlaca % 2;
                            mapa[filas][columnas] = 1;
                            placas[posicionPlaca] = placa;

                            System.out.println("              INGRESO REGISTRADO CORRECTAMENTE");
                            System.out.println("Placa: " + placa);
                            System.out.println("Espacio ocupado: " + espacioSeleccionado);

                            ocupados++;
                            if (contadorHistorial < 20) {
                                tipoMovimiento[contadorHistorial] = "INGRESO";
                                historialPlaca[contadorHistorial] = placa;
                                historialEspacio[contadorHistorial] = espacioSeleccionado;
                                contadorHistorial++;
                            } else {
                                System.out.println("Aviso: el historial esta lleno; el ingreso no se guardo en el historial.");
                            }
                        }
                    } else {
                        System.out.println("                     PARQUEADERO LLENO");
                        System.out.println("No existen espacios disponibles en este momento.");
                        System.out.println("No se puede registrar el ingreso del vehiculo.");
                    }
                    break;
                }

                case 3: {
                    System.out.println("                   REGISTRO DE SALIDA");
                    String espacioSeleccionado;
                    int posicionPlaca;
                    do {
                        System.out.println("Ingrese el espacio que desea salirse:");
                        System.out.println("A1 - A2");
                        System.out.println("B1 - B2");
                        espacioSeleccionado = sc.nextLine().trim();
                        posicionPlaca = obtenerPosicion(espacioSeleccionado);
                        if (posicionPlaca == -1) {
                            System.out.println("Espacio incorrecto. Intente nuevamente.");
                        }
                    } while (posicionPlaca == -1);

                    int filas = posicionPlaca / 2;
                    int columnas = posicionPlaca % 2;

                    if (mapa[filas][columnas] == 1) {
                        System.out.println("              SALIDA REGISTRADA CORRECTAMENTE");
                        System.out.println("Placa del vehiculo: " + placas[posicionPlaca]);
                        System.out.println("Espacio liberado: " + espacioSeleccionado);

                        // Guardar movimiento antes de borrar la placa
                        if (contadorHistorial < 20) {
                            tipoMovimiento[contadorHistorial] = "SALIDA";
                            historialPlaca[contadorHistorial] = placas[posicionPlaca];
                            historialEspacio[contadorHistorial] = espacioSeleccionado;
                            contadorHistorial++;
                        } else {
                            System.out.println("Aviso: el historial esta lleno; la salida no se guardo en el historial.");
                        }

                        mapa[filas][columnas] = 0;
                        placas[posicionPlaca] = "";
                        ocupados--;
                        System.out.println("El espacio " + espacioSeleccionado + " ahora esta disponible.");
                    } else {
                        System.out.println("                    ESPACIO LIBRE");
                        System.out.println("El espacio " + espacioSeleccionado + " ya se encuentra libre.");
                        System.out.println("No existe un vehiculo para registrar su salida.");
                    }
                    break;
                }

                case 4: {
                    System.out.println("              CONSULTAR ESPACIO ESPECIFICO");
                    System.out.println("Posiciones del parqueadero:");
                    System.out.println("A1   A2");
                    System.out.println("B1   B2");
                    System.out.println("Ingrese el espacio que desea consultar:");
                    String espacioSeleccionado = sc.nextLine().trim();
                    int posicionPlaca = obtenerPosicion(espacioSeleccionado);

                    if (posicionPlaca != -1) {
                        int filas = posicionPlaca / 2;
                        int columnas = posicionPlaca % 2;
                        System.out.println("Espacio consultado: " + espacioSeleccionado);
                        if (mapa[filas][columnas] == 0) {
                            System.out.println("Estado: LIBRE (0)");
                        } else {
                            System.out.println("Estado: OCUPADO (1)");
                            System.out.println("Placa registrada: " + placas[posicionPlaca]);
                        }
                    } else {
                        System.out.println("              ESPACIO NO VALIDO");
                        System.out.println("El espacio ingresado no existe.");
                        System.out.println("Ingrese A1, A2, B1 o B2.");
                    }
                    break;
                }

                case 5:
                    mostrarMapa(mapa);
                    break;

                case 6: {
                    ocupados = 0;
                    for (int filas = 0; filas < 2; filas++) {
                        for (int columnas = 0; columnas < 2; columnas++) {
                            if (mapa[filas][columnas] == 1) {
                                ocupados++;
                            }
                        }
                    }
                    double porcentajeOcupacion = calcularPorcentaje(ocupados, espaciosTotales);
                    System.out.println("                 PORCENTAJE DE OCUPACION");
                    System.out.println("Espacios ocupados: " + ocupados + " de " + espaciosTotales);
                    System.out.println("Porcentaje de ocupacion: " + porcentajeOcupacion + "%");
                    break;
                }

                case 7:
                    System.out.println("                  HISTORIAL DE MOVIMIENTOS");
                    if (contadorHistorial == 0) {
                        System.out.println("No existen movimientos registrados.");
                    } else {
                        for (int contador = 0; contador < contadorHistorial; contador++) {
                            System.out.println("Movimiento #" + (contador + 1));
                            System.out.println("Tipo: " + tipoMovimiento[contador]);
                            System.out.println("Placa: " + historialPlaca[contador]);
                            System.out.println("Espacio: " + historialEspacio[contador]);
                        }
                    }
                    break;

                case 8:
                    System.out.println("                 CERRANDO SISTEMA");
                    System.out.println("Gracias por utilizar el Sistema de Parqueadero La Piazza.");
                    System.out.println("Programa finalizado correctamente.");
                    break;

                default:
                    System.out.println("Opcion incorrecta.");
                    System.out.println("Seleccione una opcion valida del 1 al 8.");
                    break;
            }
        }
        sc.close();
    }

    // ---------- SubProceso MostrarMenu ----------
    static void mostrarMenu() {
        System.out.println("                  SISTEMA DE PARQUEADERO: LA PIAZZA");
        System.out.println("1. Ver disponibilidad del parqueadero.");
        System.out.println("2. Registrar ingreso de vehiculo.");
        System.out.println("3. Registrar salida de vehiculo.");
        System.out.println("4. Consultar un espacio especifico.");
        System.out.println("5. Visualizar mapa del parqueadero.");
        System.out.println("6. Ver porcentaje de ocupacion.");
        System.out.println("7. Consultar historial de movimientos.");
        System.out.println("8. Salir del sistema.");
        System.out.println("                 Seleccione una opcion del 1 al 8:");
    }

    // ---------- Funcion BuscarEspacioLibre ----------
    static String buscarEspacioLibre(int[][] mapa) {
        for (int filas = 0; filas < 2; filas++) {
            for (int columnas = 0; columnas < 2; columnas++) {
                if (mapa[filas][columnas] == 0) {
                    return NOMBRES_ESPACIOS[filas * 2 + columnas];
                }
            }
        }
        return "LLENO";
    }

    // ---------- SubProceso MostrarMapa ----------
    static void mostrarMapa(int[][] mapa) {
        System.out.println("               MAPA DEL PARQUEADERO");
        System.out.println("0 = LIBRE");
        System.out.println("1 = OCUPADO");
        System.out.println();
        System.out.println("Posiciones:");
        System.out.println("A1   A2");
        System.out.println("B1   B2");
        System.out.println();
        System.out.println("Estados:");
        for (int filas = 0; filas < 2; filas++) {
            for (int columnas = 0; columnas < 2; columnas++) {
                System.out.print(mapa[filas][columnas] + "    ");
            }
            System.out.println();
        }
    }

    // ---------- Funcion CalcularPorcentaje ----------
    static double calcularPorcentaje(int ocupados, int espaciosTotales) {
        return ((double) ocupados / espaciosTotales) * 100;
    }

    // ---------- Auxiliar: identificador -> posición (0..3) o -1 si no existe ----------
    static int obtenerPosicion(String espacio) {
        for (int i = 0; i < NOMBRES_ESPACIOS.length; i++) {
            if (NOMBRES_ESPACIOS[i].equals(espacio)) {
                return i;
            }
        }
        return -1;
    }
}
