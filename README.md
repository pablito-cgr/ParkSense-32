# ParkSense 32

Sistema de estacionamiento inteligente basado en ESP32.

## Estructura del Proyecto

- `PSeInt/` - Diagramas de flujo y pseudocódigo en PSeInt
- `Java/` - Código fuente en Java
- `Electronica/` - Código fuente y esquemas de electrónica (ESP32)
- `public/` - Interfaz web del sistema
